# 银铃 / Yinling · 成品包

银白长发、豆豆眼的小伙伴。包含 9 组动作、16 个注视方向和 73 帧。

![动作预览](docs/previews/all-states.gif)

将完整 `spritesheet.png` 附到具备 Pets 工具的 Codex / ChatGPT 会话，请求验证、创建并启用「银铃」。详细步骤见 [INSTALL.md](INSTALL.md)。

`pet.json` 记录公开布局和预览时长，开发者格式见 [图集说明](docs/ATLAS_FORMAT.md)，检查记录见 [质量记录](docs/QUALITY.md)。

角色图像、源帧和预览供个人非商业用途免费使用，条件见 [素材许可](LICENSE-ASSETS.txt)。文字说明采用 [MIT](LICENSE)。分享原始素材时保留 [来源与署名](CREDITS.md) 及许可。

完整源码与制作工具请下载同版本的 `yinling-source` 包，或访问本项目 GitHub 仓库。

## English

Attach the entire `spritesheet.png` to a Codex / ChatGPT session with Pets tools enabled, then request validation, creation and selection. See INSTALL.md. The JSON describes the atlas for developers.
